# 上線與部署檢驗清單 (Go-Live Checklist)

> 專案正式發布或部署至雲端環境（GCP VM / Docker / Cloudflare）前的安全與品質檢查。

---

## 🛡️ 1. 程式碼與版本檢查
- [ ] 確定本地所有變更皆已通過測試
- [ ] 確定程式碼已 Commit 並 Push 至遠端 Git 倉庫的正確分支
- [ ] 敏感資訊（密鑰、DB 密碼、API Key）已從代碼中移除並改以 `.env` 管理

---

## 🗄️ 2. 資料庫與儲存
- [ ] 伺服器 DB 遷移腳本已測試無誤（無破壞性 DROP TABLE）
- [ ] 部署前已完成正式庫全量備份（`dump` 備份檔已妥善存放）
- [ ] 關鍵欄位索引 (Index) 與 Unique 約束已建立

---

## 🌐 3. 網路、安全與反向代理
- [ ] Nginx / Caddy 反向代理設定與 SSL (HTTPS) 憑證有效性確認
- [ ] CORS 跨域設定僅開放允許的來源網域
- [ ] 防火牆規則（開放必要埠號如 80, 443，關閉 DB 直連公開存取）

---

## 🩺 4. 監控與日誌 (Health Check & Logs)
- [ ] `/health` 或首頁端點回傳 HTTP 200
- [ ] Docker 容器設定 `restart: unless-stopped`
- [ ] 錯誤日誌輸出正常且無持續性 Fatal 報錯
